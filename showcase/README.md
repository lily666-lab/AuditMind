# 已验证RAG案例的静态预览

本目录是离线导出的历史真实问答，不提供实时问答或付费接口。三个案例分别展示在建项目收入判断、时段履约判断、知识范围外拒答。前两个仅引用财政部公开《企业会计准则第14号——收入（2017）》条文；不包含个人底稿原文。原始回答未人工改写，展示层仅将已验证引用锚点替换为本目录静态原文链接。

- `index.html`、`app.js`、`style.css`：案例选择和蓝白展示。
- `data.js`：经过白名单筛选的三个真实回答、来源和原始回答摘要Hash。
- `sources.html`：实际引用的8条公开准则原文、条款位置和Hash；已与财政部公开文本核对。

不含API调用、服务端授权、费用账本、执行锁、用户目录或原请求ID。页面使用`connect-src 'none'`，不请求模型接口。资料版本、业务适用性和专业结论仍需人工复核。

公开原文：[财政部会计司](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694006.htm)。
